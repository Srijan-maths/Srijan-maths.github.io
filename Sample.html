Problem 2 · JEE Advanced Level 9.8 / 10 Class 11-12

JEE Advanced Level

Two periodic, continuous and infinitely differentiable functions of x are defined such that: \\$f(x) = \frac{1}{2i}\sum_{n=k}^\infty \frac{(ix)^n - (-ix)^n}{\Gamma(n+1)}$; where $\Gamma(n) = (n-1)!$ \\ \\ $g(x) = \sum_{n=k}^\infty (-1)^n\frac{x^2n}{4^n\cdot n!(\frac{1}{2})_n}$; where $(\frac{1}{k})_n = \frac{1}{k}\cdot\frac{3}{k}\cdot\frac{5}{k}\cdot...\cdot \frac{2n-1}{k}$\\ \\ Let a matrix be defined as: \[ A= \begin{bmatrix} f(x) & g(x)\\ 2k & f(x) \end{bmatrix} + \begin{bmatrix} k & 2k\\ g(x) & 5k \end{bmatrix} \] \\ If $A_1$ refers to the matrix which contains the first order derivative of each element of A, $A_2$ refers to the matrix which contains the second order derivative of each element of A,..., $A_n$ refers to the matrix which contains the nth order derivative of each element of A: \[ A_n= \begin{bmatrix} \frac{d^nf(x)}{dx^n} & \frac{d^ng(x)}{dx^n}\\ \\ \frac{d^n2k}{dx^n} & \frac{d^nf(x)}{dx^n} \end{bmatrix} + \begin{bmatrix} \frac{d^nk}{dx^n} & \frac{d^n2k}{dx^n}\\ \\ \frac{d^ng(x)}{dx^n} & \frac{d^n5k}{dx^n} \end{bmatrix} \] And if $|A_{2027}|(x)$ is a continuous, periodic and infinitely differentiable function of x such that: $$\int_k^{sin^{-1}(-|A_{2027}|(k))}|A_{2027}|dx = k$$ Find the value of: $$6\lim_{x\xrightarrow{}k}\frac{sin^{k-1}x - x^{k+1}}{x^3}$$
