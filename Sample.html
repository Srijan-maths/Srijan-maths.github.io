Problem 2 · JEE Advanced Level 9.8 / 10 Class 11-12

JEE Advanced Level

Two periodic, continuous and infinitely differentiable functions of \(x\) are defined such that:

\[ f(x) = \frac{1}{2i} \sum_{n=k}^{\infty} \frac{(ix)^n-(-ix)^n} {\Gamma(n+1)} \]

where

\[ \Gamma(n)=(n-1)! \]

and

\[ g(x) = \sum_{n=k}^{\infty} (-1)^n \frac{x^{2n}} {4^n\cdot n!\left(\frac{1}{2}\right)_n} \]

where

\[ \left(\frac{1}{k}\right)_n = \frac{1}{k} \cdot \frac{3}{k} \cdot \frac{5}{k} \cdots \frac{2n-1}{k} \]

Let a matrix be defined as:

\[ A= \begin{bmatrix} f(x) & g(x)\\ 2k & f(x) \end{bmatrix} + \begin{bmatrix} k & 2k\\ g(x) & 5k \end{bmatrix} \]

If \(A_1\) refers to the matrix which contains the first order derivative of each element of \(A\), \(A_2\) refers to the matrix which contains the second order derivative of each element of \(A\), and so on, then:

\[ A_n= \begin{bmatrix} \frac{d^nf(x)}{dx^n} & \frac{d^ng(x)}{dx^n} \\[8pt] \frac{d^n(2k)}{dx^n} & \frac{d^nf(x)}{dx^n} \end{bmatrix} + \begin{bmatrix} \frac{d^nk}{dx^n} & \frac{d^n(2k)}{dx^n} \\[8pt] \frac{d^ng(x)}{dx^n} & \frac{d^n(5k)}{dx^n} \end{bmatrix} \]

And if

\[ |A_{2027}|(x) \]

is a continuous, periodic and infinitely differentiable function of \(x\) such that:

\[ \int_k^{\sin^{-1}(-|A_{2027}|(k))} |A_{2027}|\,dx = k \]

Find the value of:

\[ 6 \lim_{x\to k} \frac{\sin^{k-1}x-x^{k+1}} {x^3} \]
Problem 3 · Higher Mathematics 9.7 / 10 College Level

Higher Mathematics

Let:

$$u=(x-y)\cdot\sin(x+y)+e^{x+y}$$

If:

\[ \frac{\partial^n u}{\partial x^n} + \frac{\partial^n u}{\partial y^n} = 2 \frac{\partial^n u} {\partial x^{n/2}\partial y^{n/2}} \]

and

\[ n= \{x:x\leq100,\ x=a_1,a_2,\ldots,a_k;\ a_k>a_{k-1}\} \]

Let

\[ f:(-1,1)\rightarrow\mathbb{R} \]

be a function defined as:

\[ f(x) = x^{a_1/2} + \frac{x^{a_1}}{4} + 27x^{a_2-1} + \frac{x^{a_2}}{a_8} + x^{a_2+1} \left( 30a_{50} +(a_3-1)^3 \right) +\cdots \]

Let

\[ g:(-1,1)\rightarrow\mathbb{R} \]

be a function defined as:

\[ g(x) = \sum_{k=\frac{a_{50}-a_{49}}{2}}^\infty \frac{1}{k} \int_{a_{50}-25a_2}^{x} f\left(\frac{t}{k}\right) \frac{ d f\left(\frac{t}{k}\right) }{ d\left(\frac{t}{k}\right) } \,dt \]

Find the value of:

\[ \lim_{x\to0} \left( \frac{g'(x)} {\pi^2f(x)} \cdot \frac{1}{ \displaystyle \lim_{x\to a_{20}-2a_{10}} \frac{\sin^{-1}x-x}{x^3} } \right) \]
