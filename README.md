# 📚 About

The goal of this project is to create challenging, original mathematics problems that encourage deep thinking rather than routine computation.

Problems span topics from:

* Algebra
* Geometry
* Trigonometry
* Calculus
* Number Theory
* Combinatorics
* Probability
* Functional Equations
* Inequalities
* Coordinate Geometry
* Linear Algebra
* Miscellaneous Challenges

The intended audience includes advanced high-school students, Olympiad participants, and anyone who enjoys difficult mathematics.
